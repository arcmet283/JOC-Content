DROP YOUR YOUTUBE STUDIO CSV EXPORTS IN THIS FOLDER.

HOW TO EXPORT:
1. Go to YouTube Studio
2. Click Analytics in the left menu
3. Click on a video, or go to the Overview tab for channel-wide data
4. Click the Export icon (top right, looks like a down arrow)
5. Save the CSV file here with the video name (e.g. Ian-Wheeler.csv)
6. Repeat for each published video
7. Open GitHub Desktop and push

The Monthly Analytics Review agent reads this folder every 26th and updates Channel Intelligence automatically.
